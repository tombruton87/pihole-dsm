Pi-hole only sees the devices that use it for DNS. The easy way is to tell your router — then every device on the network uses it.

Point your network at Pi-hole

DNS server:

  1. In your router's settings, find DHCP or LAN → DNS server, and enter the address above (as the only DNS server — a second one would let ads through).
  2. Reconnect a phone or restart a computer, so it picks up the change. Today's numbers on the Blocking tab start to move.
  3. Can't change the router? Set the DNS server on each device instead (Wi-Fi settings → DNS → manual).
